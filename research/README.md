# Research snapshots

The Makepad files in this directory are reference snapshots collected on
2026-09-13 from the public [`makepad/makepad` repository](https://github.com/makepad/makepad/tree/work).
They are not compiled into Kernel Atlas. Their upstream MIT license is retained
in `makepad-LICENSE` (retrieved from the public repository on 2026-10-06).

`kernel-sha256sums.asc` is the upstream kernel.org checksum document for the
Linux 1.0 archive. The Linux corpus and its original license are retained in
`Corpus/linux/`.
